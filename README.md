# Internet Usage and Data Consumption Analytics

## Project Overview

This project analyzes large-scale internet usage and data consumption records using Apache Hadoop HDFS, Apache Spark, Spark SQL, Apache Hive, Spark MLlib, and Power BI.

## Technology Stack

- HDFS
- Apache Spark / PySpark
- Spark SQL
- Apache Hive
- Spark MLlib
- Python
- Parquet
- Power BI

## Dataset

The project uses an 800,000-record synthetic telecom internet usage dataset containing application usage, data consumption, session duration, operator, network type, and time information.

## Architecture

Dataset
→ HDFS
→ Apache Spark
→ Data Processing
→ Hive / Spark SQL
→ Feature Engineering
→ Spark MLlib
→ Power BI
